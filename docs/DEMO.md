# 5-Minute Demo Script

Goal: show every rubric area in 5 minutes. `npm run demo` performs steps 3–8 automatically and narrates each step; the rest is on-screen walk-through. Record with any screen recorder (the demo video itself is not generated by the repository).

## Setup (before recording)

```bash
npm ci && npm run gen:env > .env
docker compose --env-file .env -f infra/docker/docker-compose.yml up --build -d     # or local Postgres/Redis, see README
# local alternative:
#   MIN_BOOKING_LEAD_MINUTES=0 RATE_LIMIT_AUTH_PER_MIN=1000 npm run dev  &  METRICS_PORT=9465 npm run dev:worker &
```
For the compose route add `MIN_BOOKING_LEAD_MINUTES=0` and `RATE_LIMIT_AUTH_PER_MIN=1000` to the `api` service environment so the demo's near-term slots are bookable.
